# Results

No benchmark result is claimed in the reorganized repository.

Future runs should record at least:

- commit hash and configuration file;
- dataset revision and exact split;
- Python, PyTorch, Transformers, CUDA, and GPU versions;
- total training steps and wall-clock time;
- final training and validation loss;
- a small loss curve or structured `metrics.json` file.

Large checkpoints should be stored outside Git rather than committed to this directory.
